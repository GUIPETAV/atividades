# Atividades Diversas

Material de aula/atividade prática, organizado para consulta e reuso.

## Visão Geral

Coleção de atividades em PDF, reunidas neste repositório.

## Estrutura do Repositório

| Arquivo | Descrição |
|---|---|
| `*.pdf` | Enunciados/materiais das atividades em PDF |

## Como Usar

Baixe e abra os arquivos PDF para consultar o conteúdo de cada atividade.

## Observações

Arquivos sem nomes descritivos — recomenda-se renomear os PDFs para facilitar a consulta futura.
